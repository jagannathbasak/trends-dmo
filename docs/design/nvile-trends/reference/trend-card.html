  1. 1Category — the area it sits in. Links to that area's filtered view.
  2. 2Direction — emerging, accelerating, steady or declining. Arrow plus word, never colour alone.
  3. 3Trend name — plain language, no jargon. Display face, tight tracking.
  4. 4What is changing — one sentence. The mechanism, not the symptom.
  5. 5Momentum — a derived figure, so it carries ◇. Score, sparkline and period delta read together.
  6. 6Key signals — up to three, each tagged by evidence tier: ● verified, ◦ signal, ◇ estimate. Every one is traceable on the trend page.
  7. 7Top catalysts — why it is moving, ranked by weighted contribution. Two on the card, all of them on the trend page.
  8. 8The forecast teaser — model output, so it carries ◈ and never appears without its confidence.
  9. 9Into the depth — one action, always the same words, leading to the evidence and the forecast.
  10. Compact variant, used in the Emerging / Accelerating / Declining columns: rank, name, stage, sparkline and the ◈ probability. Everything else is dropped.
